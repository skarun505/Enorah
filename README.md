# Enorah - Eden Partner Circle

An immersive, responsive web experience showcasing the Eden Partner Circle initiative by Enorah.

## Overview

- **Design System**: Tailored dark moss / night forest aesthetics, custom typography (`Instrument Serif` & `Manrope`), fluid responsive clamp layouts.
- **Components**:
  - Interactive hero banner with crossfade slides and progress indicators
  - Dynamic partnership tier comparison & returns estimator
  - Scrollytelling visual narrative & chapter progressions
  - Mobile-optimized inquiry and booking forms

## Project Structure

```
├── index.html                  # Default entry point
├── Eden-Partner-Circle.html    # Full showcase edition
├── .gitignore
└── README.md
```

## Getting Started

Open `index.html` in any modern web browser or serve via any static HTTP server (e.g. `npx serve`, Live Server, GitHub Pages, or Vercel).
